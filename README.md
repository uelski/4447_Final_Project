# Denver Data Project
## University of Denver Comp_4447
Stuti, Namoos, and Sam

### Data Source
We pulled most of the data for this project from the [Denver Open Data Catalog](https://opendata-geospatialdenver.hub.arcgis.com/).

Neighborhood geodata was provided from the [State of Colorado](https://data.colorado.gov/Municipal/Denver-Statistical-Neighborhoods/6g4b-w8bd)

### Overview
This is a shared project for work on our final project for DU comp_4447 using Denver city data.

Our goal is to explore the relationships between neighborhood crime rates, demographics, after school programs and equity scores. We plan to use visualizations and models to try and answer subquestions such as:
- What effect does after school program counts have on crime rates and equity scores?
- What factor does time play into crime incidents?
- What features are important in determining neighborhood crime reates?
- What features are important in determining neighborhood equity scores?

We answered these questions and more to varying degress of success, and we were able to implement the skills and techniques we learned from class.
